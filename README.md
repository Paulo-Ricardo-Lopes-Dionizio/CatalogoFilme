# CatalogoFilme
Projeto desenvolvido com parceria de 2 colegas, Site desenvolvido com um sistema de armazém de dados utilizando Python e SQL para a estrutura do sistema.
 - Back-End: desenvolvido por luís guilherme josepette marchetto e Paulo Ricardo Lopes Dionizio
 - Front-end: luiz fernando bertaglia e Paulo Ricardo Lopes Dionizio

# Resumo
Site desenvolvido para fazer armazém de dados sobre filmes e formar um "Catálogo de Filmes", utilizando Python para a estrutura do sistema e banco de dados SQL para armazenar todas as informações dos filmes e exibi-las no site com um sistema anônimo de inserção de dados. O Python foi responsável por criar a estrutura do sistema de armazém de dados, facilitando a integração entre o front-end e o banco de dados. O usuário pode adicionar informações sobre filmes, como título, gênero, sinopse, ano de lançamento e outros detalhes, sem a necessidade de cadastro, garantindo uma interação simples e prática com o sistema. A plataforma também permite a visualização e busca por filmes no catálogo, proporcionando uma experiência dinâmica para os visitantes.
