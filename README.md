# 🎬 CatálogoFilme - Armazém de Dados para Filmes

Projeto desenvolvido em parceria com colegas no curso de Ciência da Computação.  
Este site funciona como um **catálogo de filmes**, utilizando **Python** e **SQL** para gerenciar o armazenamento e exibição dos dados de forma dinâmica.

---

## ⚙️ Tecnologias Utilizadas

- 🐍 **Python** – Responsável pela lógica do sistema e integração com o banco de dados.
- 🗃️ **SQL** – Armazena as informações dos filmes.
- 🌐 **HTML/CSS/JavaScript** – Interface amigável e dinâmica para o usuário.

---

## 🧠 Resumo do Projeto

O objetivo do sistema é permitir que usuários anônimos cadastrem e consultem informações sobre filmes, como:

- 🎞️ Título  
- 🧬 Gênero  
- 📝 Sinopse  
- 📅 Ano de Lançamento  
- 🎥 Outros Detalhes

Sem a necessidade de login ou cadastro, o site proporciona uma **experiência simples e acessível**, ideal para manter um acervo colaborativo de títulos.  
Além do cadastro, o sistema também oferece **busca e visualização rápida** dos filmes cadastrados.
